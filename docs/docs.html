CLI Snoopy

Interactive terminal ASCII art viewer written in Go.

Usage

Launch the utility directly from your terminal by typing the path with the executable name

Renaming the tool to snoopy is personally recommended

Navigate the prompt by typing the artwork number (1-4) and pressing Enter. Type q at any time to cleanly exit the program.

Command-Line Flags

Flag Description Example
--version Displays the currently installed version. snoopy --version
--update Checks GitHub Releases and performs an in-place binary update. snoopy --update
--docs Launches the local documentation web server. snoopy --docs
